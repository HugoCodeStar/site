# Laboratoire 1 — Exercices de conversion de bases

## Objectifs

Pratiquer les conversions entre les bases **binaire (2)**, **octale (8)**, **décimale (10)**
et **hexadécimale (16)**, ainsi que les notations associées.

## Consignes

- Faire tous les calculs **à la main**, puis vérifier les résultats.
- Présenter les étapes (divisions successives, regroupement de bits, etc.).
- Rappels :
  - Vers la base 10 : **somme des chiffres × puissance de la base**.
  - Depuis la base 10 : **divisions successives** (restes lus de bas en haut).
  - Binaire ↔ hexadécimal : regroupement par paquets de **4 bits**.
  - Binaire ↔ octal : regroupement par paquets de **3 bits**.
