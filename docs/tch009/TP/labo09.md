# Laboratoire 9 — Tableaux et chaînes de caractères

## Consignes

Écrire, compiler et tester chaque programme. Pour les chaînes, réserver un caractère de plus
pour le `'\0'`.

## Exercices

| N° | Exercice |
|----|----------|
| 1  | Calculer la somme et la moyenne d'un tableau d'entiers. |
| 2  | Trouver le maximum et le minimum d'un tableau. |
| 3  | Rechercher un élément dans un tableau et afficher sa position (ou −1). |
| 4  | Inverser un tableau (premier ↔ dernier, etc.). |
| 5  | Déclarer et afficher une matrice 3×3. |
| 6  | Calculer la somme de chaque ligne d'une matrice. |
| 7  | Écrire une fonction qui retourne la longueur d'une chaîne (sans `strlen`). |
| 8  | Écrire une fonction qui copie une chaîne (sans `strcpy`). |
| 9  | Écrire une fonction qui compare deux chaînes (sans `strcmp`). |
| 10 | Écrire une fonction qui concatène deux chaînes (sans `strcat`). |
| 11 | Compter le nombre de voyelles dans une chaîne. |
| 12 | Inverser une chaîne de caractères. |
