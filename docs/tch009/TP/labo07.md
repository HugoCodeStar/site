# Laboratoire 7 — Programmation modulaire

## Consignes

Créer un projet CLion avec plusieurs fichiers. Tester la compilation et l'exécution.

## Exercices

| N° | Exercice |
|----|----------|
| 1  | Créer `maths.h` contenant les prototypes de `carre(int)` et `cube(int)`. |
| 2  | Créer `maths.c` implémentant `carre` et `cube`. |
| 3  | Créer `main.c` qui inclut `maths.h` et affiche `carre(4)` et `cube(3)`. |
| 4  | Ajouter un garde-fou (`#ifndef`/`#define`/`#endif`) dans `maths.h`. |
| 5  | Écrire une fonction `void afficherMenu()` qui ne retourne rien. |
| 6  | Illustrer la différence entre variable locale et variable globale. |
| 7  | Illustrer une variable `static` qui conserve sa valeur entre les appels. |
| 8  | En approche descendante, dessiner la structure d'un programme de calculatrice. |
| 9  | Expliquer le rôle de l'édition de liens. |
| 10 | Créer un module `conversion` (`conversion.h`/`conversion.c`) avec `celsiusVersFahrenheit(double)`. |
