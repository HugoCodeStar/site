# Laboratoire 5 — Structures conditionnelles

## Consignes

Écrire, compiler et tester chaque programme. Prévoir plusieurs cas de test.

## Exercices

| N° | Exercice |
|----|----------|
| 1  | Écrire un programme qui indique si un entier est positif, négatif ou nul. |
| 2  | Écrire un programme qui vérifie si un nombre est pair ou impair. |
| 3  | Écrire un programme qui affiche le maximum de deux nombres. |
| 4  | Écrire un programme qui affiche le maximum de trois nombres. |
| 5  | Convertir une note (0-100) en lettre (A/B/C/D/F) avec `if/else if`. |
| 6  | Refaire l'exercice 5 avec `switch` (sur `note / 10`). |
| 7  | Écrire un menu avec `switch` : 1 = Café, 2 = Thé, 3 = Chocolat. |
| 8  | Écrire le maximum de deux nombres avec l'opérateur ternaire `?:`. |
| 9  | Écrire un programme qui indique si une année est bissextile. |
| 10 | Écrire un programme qui indique si un caractère est une voyelle ou une consonne. |
