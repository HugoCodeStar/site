# Laboratoire 2 — Représentation binaire des données

## Consignes

Répondre à chaque question en montrant les étapes. Vérifier les plages et les codes demandés.

## Exercices

| N° | Exercice |
|----|----------|
| 1  | Convertir `42₁₀` en binaire sur 8 bits (non signé). |
| 2  | Convertir `200₁₀` en binaire sur 8 bits (non signé). |
| 3  | Quel est le plus grand entier non signé sur 8 bits ? Sur 16 bits ? |
| 4  | Représenter `−12` en complément à deux sur 8 bits. |
| 5  | Représenter `−1` en complément à deux sur 8 bits. |
| 6  | Décoder `11110000₂` (8 bits, signé). |
| 7  | Décoder `10000000₂` (8 bits, signé). |
| 8  | Quelle est la plage des entiers signés sur 8 bits ? Sur 16 bits ? |
| 9  | Donner le code ASCII (décimal et hexadécimal) de `'A'`, `'Z'`, `'a'`, `'z'`, `'0'`, `'9'`. |
| 10 | Décoder la suite de codes ASCII : `72 105 33`. |
| 11 | Sur 8 bits non signés, que vaut `255 + 1` ? Expliquer. |
| 12 | Calculer le complément à deux de `01101010₂`. |
