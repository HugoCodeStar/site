# Laboratoire 6 — Structures itératives et fonctions

## Consignes

Écrire, compiler et tester chaque programme. Pour les fonctions, écrire le prototype puis
l'implémentation.

## Exercices

| N° | Exercice |
|----|----------|
| 1  | Afficher les nombres de 1 à 10 avec `while`. |
| 2  | Afficher les nombres de 1 à 10 avec `for`. |
| 3  | Calculer la somme des n premiers entiers avec `for`. |
| 4  | Calculer la factorielle de n avec `for`. |
| 5  | Afficher la table de multiplication d'un nombre donné. |
| 6  | Demander un entier positif avec `do…while` (valider la saisie). |
| 7  | Écrire une fonction `somme(int a, int b)` qui retourne `a + b`. |
| 8  | Écrire une fonction `max2(int a, int b)` qui retourne le plus grand. |
| 9  | Écrire une fonction `estPremier(int n)` qui retourne 1 si n est premier, 0 sinon. |
| 10 | Compter le nombre de chiffres d'un entier avec `while`. |
